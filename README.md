# СантехУрал: демо нового интернет-магазина

Кликабельный прототип обновлённого сайта [santechural.ru](https://www.santechural.ru/) в стиле divan.ru.
Адаптивный (mobile-first), работает без сервера.

## Что внутри

| Страница | Что показывает |
|---|---|
| Главная | Промо-слайдер, плитки категорий, хиты, скидки, калькулятор мощности радиатора по площади |
| Категория | Подкатегории, сортировка, фильтры (на телефоне выезжают снизу), «только в наличии» |
| Карточка товара | Цена, остаток, сроки самовывоза и доставки, характеристики, похожие товары, липкая кнопка покупки на телефоне |
| Поиск | Подсказки при вводе, исправление раскладки, опечаток, транслит брендов, синонимы, артикулы |
| Корзина | Предупреждение, если количество больше остатка, «не забудьте для монтажа» (комплектующие) |
| Оформление | Физлицо / организация (ИНН, оплата по счёту), самовывоз / доставка, маска телефона, проверка полей |

Категории в демо: мойки кухонные, смесители G-Lauf, смесители FRAP, радиаторы стальные,
комплектующие для радиаторов, Valtec.

## Файлы

- `index.html` — разметка и стили (дизайн-токены в `:root`)
- `data.js` — каталог. **Товары, цены и остатки условные (артикулы DEMO-\*)**. В рабочей версии заменяется выгрузкой из Битрикс/1С
- `images.js` — SVG-иллюстрации товаров; в рабочей версии — фото из Битрикса
- `search.js` — поисковый движок (можно перенести в обработчик поиска Битрикса)
- `app.js` — страницы, корзина, избранное, оформление заказа
- `build.sh` — собирает `docs/` для GitHub Pages

## Запуск

Локально: `./build.sh`, затем открыть `docs/index.html` в браузере
(или `python3 -m http.server -d docs`).

GitHub Pages: Settings → Pages → Branch: эта ветка, папка `/docs`.

| Адрес | Что |
|---|---|
| https://mustravel.github.io/STU/ | Демо 1: дизайн в стиле divan.ru (эта ветка) |
| https://mustravel.github.io/STU/v2/ | Демо 2: дизайн в стиле lamoda.ru (собрано из ветки `lamoda-demo`) |
| https://mustravel.github.io/STU/v3/ | Демо 3: дизайн в стиле sportmaster.ru (собрано из ветки `sportmaster-demo`) |
| https://mustravel.github.io/STU/v4/ | Демо 4: дизайн sportmaster + шрифты lamoda (собрано из ветки `sm-lamoda-fonts`) |

Обновить демо 2, 3 или 4: в ветке `lamoda-demo` / `sportmaster-demo` / `sm-lamoda-fonts` выполнить `./build.sh`,
затем скопировать `docs/index.html` и `docs/*.js` в `docs/v2/` / `docs/v3/` / `docs/v4/` этой ветки.
